The accuracy ladder

A resumable escalation campaign runs inside GitHub Actions. Each rung keeps every previous trick and adds one; state is committed back so every scheduled run continues where the last stopped.

    v0.3.0 — the 3× goal

    Current campaign best: . Version 0.3.0 targets a 3× reduction of the validation error rate — cutting referable-DR error from ~11% to ≤3.7% (accuracy ≥ 96.3%) on the way to the 97% goal.

    • s6-mixup — mixup (α = 0.2) + label smoothing on top of the full s5 stack: stronger regularization at the escalated resolution.
    • s7-distill — self-distillation: the soup teacher's soft ordinal logits (T = 3) train a same-size student, transferring the ensemble's dark knowledge into one deployable model.
    • Contract unchanged — every version keeps (1,3,H,W) → (1,5), so this playground tests them all without code changes.

    Mobile contract

    • Size budget — INT8 export ≤ 5 MB (current flagship: 3.4 MB, 3.7× compression, parity drift < 0.004).
    • Latency budget — ≤ 120 ms per inference on mid-tier Android CPU.
    • Calibration — temperature-scaled; ECE tracked on every eval.
    • Honesty gate — the 97% claim only counts when the Wilson 95% CI lower bound clears 0.97 with n ≥ 1000.

    Research & education only — not a medical device. Predictions must not be used for clinical decisions.
